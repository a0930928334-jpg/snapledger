# 01 需求文档

## 1. 产品定位

SnapLedger 是一个**本地优先**的个人记账 App，运行在安卓和 Windows 上。银行流水截图先交给通用 AI（ChatGPT 或 Claude）转换成统一的 JSON 格式，App 导入后负责**校验、对账、去重、自动分类和统计**。

核心理念：**AI 输出不可靠，App 负责把关。** AI 只做"看图抄数据"，判断交给 App 里确定性的规则，最后由你确认。

## 2. 用户与场景

- **用户**：只有你自己。英国留学生，主要用汇丰英国借记卡，币种 GBP。
- **设备**：用 iPhone 截图；在安卓手机或 Windows 电脑上导入，两边都会用。
- **频率**：每两三天到一周导入一次，每次大约 1–3 张截图，截图之间会有重叠。
- **主要目标**：看清钱花在哪、花了多少。
- **次要目标**：预算控制、月度趋势、月度总额。

## 3. 核心工作流

1. 在汇丰 App 里截取 Completed（已入账）部分的交易列表，可以有重叠。
2. 在已经设置好提示词的 ChatGPT 或 Claude 项目里，按顺序发送截图。
3. AI 返回一段 JSON 代码块。
4. 在 App 里导入：复制后点"从剪贴板导入"、粘贴，或者在安卓上用分享菜单。
5. App 依次完成解析、格式校验、截图间对齐、去重、对账、自动分类，然后显示**预览页**：绿色是新交易，灰色是已跳过的重复，黄色是疑似重复或不确定的字段，红色是对账不平的日期。
6. 你检查、修改，然后确认导入。你在预览里改过的分类，App 会记住，下次自动套用。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 正确性 | 金额一律用**整数最小单位**存储（GBP 存为便士），不用浮点数 |
| 隐私 | 真实流水只存在你的设备上；仓库里只有虚构数据；MVP 不联网 |
| 性能 | 一次导入 100 条记录，预览页在 1 秒内出结果；2 万条交易时，统计页在 1 秒内打开 |
| 可测试性 | 核心引擎是纯 Kotlin，不依赖界面和数据库，单元测试覆盖率 ≥ 80% |
| 可维护性 | 每个关键决策写一篇 ADR |

## 6. 明确不做

- 不接 Open Banking 或银行 API：需要通过受监管的第三方聚合服务，和"数据只在本地"的原则冲突。
- 不做投资和股票账户管理。
- 不做多用户或家庭共享账本。
- 不做 iOS 版：KMP 将来可以支持，但需要 Mac 来编译。
